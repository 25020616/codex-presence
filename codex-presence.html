Codex Presence

Your Codex activity, right on Discord.

Download for WindowsSource on GitHubPortable · Build Nov 20, 2026

IN THE APP

Just the right amount of detail.

The app reads local Codex session events to derive states such as thinking, coding, reading or idle.

  • Live previewPreview the Discord activity card in the app.
  • Customize the displayShow or hide the model and choose animated or static artwork.
  • Track turn activitySee fresh tokens, cached tokens and elapsed session time.
  • Control the connectionPause, reconnect, minimize to the tray and optionally start with Windows.

For the Microsoft Store version of Codex desktop and Discord desktop on Windows. Codex CLI and Discord in the browser are currently unsupported.

BEFORE YOU START

Good to know

What does the app share?

The Discord card shows your activity state, optional model, token counts and session time. Prompts, responses, project names, paths and commands are excluded.

Do I need a Discord token or an API key?

The app connects to Discord desktop through local IPC. Sign in to Discord and turn on activity sharing.

Why hasn’t my activity updated?

Make sure both Codex desktop and Discord desktop are open. Resume Presence if paused, then choose Reconnect to Discord. Updates depend on Codex session events and its log format, so they may take a moment.

What do tokens and cache mean?

The numbers describe the latest recorded turn. See the README on GitHub for how the app calculates them.

Can I view or build the source?

The repository includes C# source code, build scripts and standalone checks. Open the codex-presence repository .

GETTING STARTED

Download, open and connect.

  1. 1
    Download and extract

    Download the ZIP and extract it to a writable folder. Keep the included license notice.

  2. 2
    Open both desktop apps

    Sign in to Discord desktop, turn on activity sharing and open Codex desktop on the same Windows account.

  3. 3
    Run Codex Presence

    Open CodexDiscordPresence.exe, start a Codex task and wait for the preview card to update.

  4. 4
    Choose what to share

    Open Display to choose what information and artwork to show. Select Pause whenever you want to stop sharing.

Requires the Microsoft Store version of Codex desktop, Discord desktop and .NET Framework 4.8 on Windows x64.
